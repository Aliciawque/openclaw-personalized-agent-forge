## Release Blurb

This bundle contains three OpenClaw skills for building personalized agents from three different source types: public creators, real-world professions, and fictional characters. It focuses on durable identity files (`soul.md`, `identity.md`, `memory.md`, `agents.md`, and `tools.md` when needed) rather than thin prompt wrappers.

## ClawHub Listing Longer Descriptions

### digital-ip-agent
Analyze a public creator's content, voice, worldview, and audience relationship, then generate a deployable OpenClaw persona package centered on `soul.md`, `identity.md`, `memory.md`, and `agents.md`.

### professional-agent-forge
Generate a complete OpenClaw agent package for a real profession, including core role logic, work workflows, knowledge structure, and practical tooling recommendations.

### fictional-companion-forge
Reconstruct a fictional character as an emotionally believable OpenClaw companion agent while preserving canon voice, trust boundaries, emotional tone, and character-specific friction.
